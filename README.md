# HTML for Beginners: practice assignments

One short practice assignment for each episode of the **HTML for Beginners** series on the [Tech with AK47](https://www.youtube.com/@techwithak47) YouTube channel. You only need a web browser and a plain text editor.

## Assignments

| Episode | Folder | Task |
|---|---|---|
| 1. What is HTML? | [ep01-first-tags](ep01-first-tags/) | Fix a broken page, then write your own page with h1, p and strong |

New folders are added as episodes come out.

## How to use

1. Watch the episode.
2. Open its folder above and read its `README.md`.
3. Start from the files in `starter/`.
4. Try it yourself first. The answer is in `solution/`.

## Get the files

- **All assignments:** select the green **Code** button, then **Download ZIP**, and unzip it.
- **One file:** open the file and select the download button (Download raw file).

## What is in each folder

| Path | What it holds |
|---|---|
| `README.md` | The task, what you need, hints and a "Done when" checklist |
| `starter/` | The files you start from |
| `solution/` | One possible answer. Check it after you try. |
