# HTML for Beginners: practice assignments

One assignment per episode of the **HTML for Beginners** series on the Tech with AK47 YouTube channel: https://www.youtube.com/@techwithak47

## How to use
1. Watch the episode.
2. Open its folder below and read `README.md`.
3. Start from the files in `starter/`.
4. Try it yourself first. The answer is in `solution/`.

To get the files: click the green **Code** button, then **Download ZIP**, and unzip it. Or open a file and use the download button.
